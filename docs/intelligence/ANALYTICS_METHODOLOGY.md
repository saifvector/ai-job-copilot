# Analytics Methodology & Descriptive Intelligence

## 1. Philosophical Grounding: Descriptive Analytics vs. Predictive Guarantees

Hiring processes are multi-faceted, competitive, and subject to external market conditions outside a candidate's direct control. Consequently, all analytical intelligence generated by **AI Job Copilot** is grounded in **strict descriptive analytics**:

> [!IMPORTANT]
> All metrics, correlation scores, and rankings reflect observed empirical patterns within the user's specific application history. They do not constitute deterministic or causal guarantees of future employment offers.

---

## 2. Mathematical Formulations & Metric Definitions

### 2.1 Conversion Rates

1. **Interview Rate ($R_{interview}$)**:
   $$R_{interview} = \frac{N_{interviews}}{N_{applications}}$$
   where $N_{interviews}$ is the number of distinct applications that produced at least one `InterviewReceived` or `OfferReceived` outcome, and $N_{applications}$ is the total volume of submitted applications.

2. **Offer Conversion Rate ($R_{offer}$)**:
   $$R_{offer} = \frac{N_{offers}}{N_{applications}}$$

3. **Rejection Rate ($R_{rejected}$)**:
   $$R_{rejected} = \frac{N_{rejected}}{N_{applications}}$$

4. **Turnaround Latency ($\Delta t_{response}$)**:
   $$\Delta t = \text{occurred\_at} - \text{application\_date}$$
   Measured in decimal days. The system presents both the arithmetic mean ($\mu$) and median ($M$) to eliminate skew from non-responsive employers.

---

### 2.2 Resume Effectiveness & Variant Testing

When comparing multiple tailored resume variants ($V_1, V_2, \dots, V_k$):
- **Variant Response Rate**:
  $$R(V_i) = \frac{\text{Interviews}(V_i)}{\text{Submissions}(V_i)}$$
- **Effectiveness Multiplier**:
  $$M(V_i, V_j) = \frac{R(V_i)}{\max(R(V_j), 0.05)}$$
  If a variant achieves a response rate significantly above baseline with a minimum sample size ($N \ge 3$), the recommendation engine surfaces structural patterns from that variant (e.g. ATS score, keyword coverage, bullet point density) to standardize across other templates.

---

### 2.3 Skill Correlation & Influence Scores

For each competency $S$:
- **Interviews Influenced ($I_S$)**: Count of applications featuring skill $S$ that achieved an interview.
- **Sample Size ($N_S$)**: Total applications containing skill $S$.
- **Empirical Skill Yield ($Y_S$)**:
  $$Y_S = \frac{I_S}{N_S}$$
- **Descriptive Correlation Score ($C_S$)**:
  $$C_S = \text{clamp}\left(2.0 \times (Y_S - Y_{baseline}), -1.0, 1.0\right)$$
  where $Y_{baseline}$ is the candidate's global interview rate.
- **Recommendation Weight**:
  - `CRITICAL`: $I_S \ge 2$ with positive correlation.
  - `HIGH`: $I_S = 1$ or average match score $\ge 85\%$.
  - `MODERATE`: $N_S \ge 3$.
  - `LOW`: $N_S < 3$.

---

### 2.4 Channel & Score Tier Yield Curves

Applications are bucketed into match score tiers:
- **Tier 1 (90%+)**: Elite fit
- **Tier 2 (80-89%)**: High fit
- **Tier 3 (70-79%)**: Moderate fit
- **Tier 4 (60-69%)**: Borderline fit
- **Tier 5 (<60%)**: Stretch

Empirical yield curves evaluate whether applying to lower tiers consumes candidate time with negligible interview returns, providing a mathematical basis for setting a minimum match filter gate (e.g. 75%+).

## 3. Data Warehouse Snapshot Architecture

To support longitudinal cohort analysis without expensive on-the-fly table scans, the Data Warehouse layer persists periodic rollups in `career_intelligence_snapshots`:

```json
{
  "total_applications": 24,
  "interview_rate": 0.25,
  "offer_rate": 0.083,
  "rejection_rate": 0.333,
  "average_response_days": 5.2,
  "metrics_payload": {
    "strategy": {
      "source_breakdown": [
        { "source": "Referral", "sent": 4, "interviews": 2, "response_rate": 0.5 },
        { "source": "LinkedIn", "sent": 20, "interviews": 4, "response_rate": 0.2 }
      ]
    },
    "companies": [
      { "company": "Anthropic AI", "applications_sent": 2, "interviews_count": 1 }
    ]
  }
}
```

This enables instant timeline querying, cohort tracking across job search quarters, and longitudinal benchmarking.
